# WORKFLOWS ESPECÍFICOS - PORTFOLIO CREATIVO

## WORKFLOW: /case-study-create
DESCRIPCIÓN: Crear case study de proyecto
CUÁNDO_USAR: Agregar nuevo trabajo al portfolio

PASOS:
1. Definir narrative arc: Challenge → Approach → Solution → Impact
2. Recopilar assets: Screenshots, mockups, videos, wireframes
3. Escribir copy enfocado en results, no solo features
4. Diseñar layout visual del case study (no solo texto)
5. Agregar testimonial del cliente (con foto y cargo)
6. Mostrar proceso: Bocetos, iteraciones, decisiones de diseño
7. Tech stack y herramientas utilizadas
8. Métricas de éxito si aplica (conversion lift, engagement)
9. Link al proyecto vivo o demo interactiva
10. Related projects al final
11. Optimizar imágenes para carga rápida sin perder calidad

## WORKFLOW: /portfolio-optimize-conversion
DESCRIPCIÓN: Optimizar para conseguir más clientes
CUÁNDO_USAR: Cuando inquiries son bajos

PASOS:
1. Analizar funnel: Visitas → Project views → Contact form starts → Submissions
2. Mejorar headline del hero (value proposition clara)
3. Agregar social proof prominente (logos de clientes conocidos)
4. Simplificar formulario de contacto (menos campos = más conversion)
5. Agregar calendly para booking directo
6. Implementar live chat (opcional pero efectivo)
7. Crear content upgrade (free audit, ebook) para capturar emails
8. A/B test de CTA copy ("Hire me" vs "Start project" vs "Let's talk")
9. Optimizar velocidad (creative sites tienden a ser pesados)
10. Mobile experience flawless (muchos revisan en móvil primero)

## WORKFLOW: /creative-animations
DESCRIPCIÓN: Implementar animaciones creativas sin sacrificar performance
CUÁNDO_USAR: Dar vida al portfolio

PASOS:
1. Auditar performance actual (baseline)
2. Implementar scroll-triggered reveals (Intersection Observer)
3. Parallax sutil en hero section (no excesivo)
4. Hover states refinados en project cards
5. Page transitions suaves (AnimatePresence en Next.js)
6. Custom cursor solo si mejora la experiencia (no gimmick)
7. Reduce motion para usuarios que lo prefieren (accesibilidad)
8. Optimizar: Usar transform y opacity (GPU accelerated)
9. Testear en dispositivos de gama baja
10. Lighthouse performance debe mantenerse &gt; 85

## WORKFLOW: /personal-brand-refresh
DESCRIPCIÓN: Actualizar branding personal
CUÁNDO_USAR: Cada 1-2 años o pivot de servicios

PASOS:
1. Auditar mensaje actual: ¿Sigue siendo relevante?
2. Actualizar bio y about page con nuevo posicionamiento
3. Refrescar foto de perfil (profesional pero accesible)
4. Actualizar servicios ofrecidos (agregar/quitar según demanda)
5. Revisar y actualizar testimonials (mantener recientes)
6. Actualizar case studies con nuevos proyectos
7. Revisar consistencia visual (colores, tipografía)
8. Actualizar resume/CV descargable
9. Announce refresh en redes sociales
10. Setup redirect si cambia estructura de URLs
