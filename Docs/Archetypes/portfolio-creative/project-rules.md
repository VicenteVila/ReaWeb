# REGLAS ESPECÍFICAS - PORTFOLIO CREATIVO
# Extensión de global-rules.md

## 1. ESTRUCTURA ESPECÍFICA

PORTFOLIO_SECTIONS:
  - Hero: Nombre, tagline, foto/ilustración, CTA (contacto)
  - About/Bio: Historia, valores, proceso de trabajo
  - Selected Work: Proyectos destacados (case studies)
  - Services: Qué ofrece (diseño, desarrollo, branding)
  - Process: Cómo trabaja (descubrimiento → entrega)
  - Testimonials: Clientes satisfechos con resultados
  - Blog/Insights: Opcional, contenido de valor
  - Contact: Formulario, email, redes, disponibilidad

## 2. DISEÑO Y ESTÉTICA

CREATIVE_DESIGN_RULES:
- Typography como elemento de diseño (fuentes display permitidas)
- Uso estratégico de whitespace (generoso, no vacío)
- Animaciones refinadas (no excesivas, purpose-driven)
- Micro-interactions en hover states
- Custom cursor opcional (pero accesible)
- Scroll-triggered animations suaves
- Dark mode casi obligatorio (estándar en creativos)
- Break the grid intencionalmente (pero con propósito)
- High-quality imagery: Proyectos en contexto real (mockups)

## 3. PROYECTOS/CASE STUDIES

PROJECT_SHOWCASE_RULES:
- Cada proyecto: Problem → Process → Solution → Results
- Galería de imágenes: Before/after, proceso, final
- Video walkthrough para proyectos interactivos
- Testimonial específico del cliente por proyecto
- Tech stack utilizado (tags visibles)
- Link a proyecto vivo o prototipo interactivo
- Descargable: Case study en PDF (para stakeholders)
- Navigation entre proyectos (anterior/siguiente)

## 4. PERSONAL BRANDING

BRANDING_RULES:
- Voz consistente: Professional pero personal
- Fotos reales (no stock photos genéricos)
- Storytelling: Por qué hace lo que hace
- Values: Qué principios guían el trabajo
- Availability status: Disponible, booked, o open for limited projects
- Social proof: Logos de clientes, press mentions, awards

## 5. CONTACTO Y CONVERSIÓN

PORTFOLIO_CONVERSION:
- CTA claro: "Start a project" o "Let's work together"
- Formulario simple: Nombre, email, proyecto, presupuesto aprox
- Calendly integrado para calls de descubrimiento
- Response time expectation (ej: "Respondo en 24h")
- FAQ para preguntas comunes (proceso, rates, timeline)
- Download resume/CV opcional
