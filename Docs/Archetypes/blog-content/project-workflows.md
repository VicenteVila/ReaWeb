# WORKFLOWS ESPECÍFICOS - BLOG/CONTENT

## WORKFLOW: /content-publish
DESCRIPCIÓN: Publicar nuevo post con optimización completa
CUÁNDO_USAR: Proceso editorial de publicación

PASOS:
1. Revisar contenido: Originalidad, gramática, estructura
2. Optimizar headline (SEO + click-worthy)
3. Crear/optimizar featured image (1200x630px mínimo)
4. Escribir meta description compelling (&lt; 160 chars)
5. Seleccionar categoría principal y tags relevantes (3-5)
6. Agregar internal links a posts relacionados existentes
7. Verificar todos los external links funcionan
8. Optimizar imágenes dentro del contenido (compress, alt text)
9. Preview en mobile y desktop
10. Schedule o publish immediately
11. Distribuir: Newsletter, redes sociales, RSS
12. Monitorear performance primeras 24h

## WORKFLOW: /newsletter-setup
DESCRIPCIÓN: Configurar sistema de newsletters
CUÁNDO_USAR: Setup inicial o migración

PASOS:
1. Seleccionar provider: ConvertKit, Mailchimp, o Buttondown
2. Crear signup forms (footer, inline, popup controlado)
3. Setup welcome email sequence (drip campaign)
4. Crear template de newsletter semanal/mensual
5. Segmentación: Por intereses, comportamiento, engagement
6. RSS to email automation para nuevos posts
7. Lead magnets para aumentar conversión (checklist, ebook)
8. Analytics: Open rates, click rates, unsubscribe rates
9. Compliance: GDPR, CAN-SPAM, doble opt-in

## WORKFLOW: /content-audit
DESCRIPCIÓN: Auditar y mejorar contenido existente
CUÁNDO_USAR: Cada 6 meses o cuando tráfico baja

PASOS:
1. Identificar posts con bajo tráfico pero potencial
2. Actualizar información desactualizada
3. Mejorar headlines y meta descriptions
4. Agregar contenido nuevo (expandir posts cortos)
5. Optimizar para keywords nuevas (search console data)
6. Mejorar internal linking
7. Actualizar imágenes y ejemplos
8. Re-publicar con fecha actualizada
9. Redirect 301 si cambia URL
10. Re-promover en redes y newsletter

## WORKFLOW: /reading-experience
DESCRIPCIÓN: Optimizar experiencia de lectura
CUÁNDO_USAR: Mejorar engagement y tiempo en página

PASOS:
1. Auditar tipografía: Tamaño, interlineado, longitud de línea
2. Implementar modo oscuro automático
3. Agregar opciones de tamaño de fuente (A- A A+)
4. Mejorar contraste para lectura prolongada
5. Sticky TOC para navegación en posts largos
6. Progress indicator visual
7. "Reading time" estimation visible
8. Highlight y share de citas seleccionadas
9. Print stylesheet funcional
10. Modo "distraction-free" opcional
