# WORKFLOWS ESPECÍFICOS - CORPORATE/BUSINESS

## WORKFLOW: /corporate-page-create
DESCRIPCIÓN: Crear página siguiendo guidelines corporativas
CUÁNDO_USAR: Nuevas páginas de servicios o industrias

PASOS:
1. Revisar brand guidelines (colores, tipografía, tono de voz)
2. Research de competitors (qué hacen bien/mal)
3. Definir objetivo de la página (lead gen, awareness, recruitment)
4. Estructurar contenido: Headline, subhead, body, CTA, social proof
5. Seleccionar/implementar visuals acordes (fotos de equipo, gráficos)
6. Asegurar consistency con navigation global
7. Implementar forms con CRM integration (Salesforce, HubSpot)
8. Setup tracking de conversiones específicas
9. Legal review si es necesario (industrias reguladas)
10. Approval de stakeholders antes de publicar

## WORKFLOW: /lead-generation-optimize
DESCRIPCIÓN: Optimizar para generación de leads B2B
CUÁNDO_USAR: Mejorar pipeline de ventas

PASOS:
1. Auditar forms: Cuántos campos, cuál es el abandonment rate
2. Implementar progressive profiling (preguntar más en segunda visita)
3. Crear landing pages específicas por industria/pain point
4. Gated content strategy: Whitepapers, reports, webinars
5. Implementar lead scoring básico (behavior tracking)
6. Setup marketing automation (nurture sequences)
7. Chatbot para qualification de leads (Drift/Intercom)
8. Retargeting campaigns para visitantes que no convirtieron
9. A/B test de CTAs ("Contact Sales" vs "Get Demo" vs "Free Consultation")
10. Integración CRM bidireccional (web → CRM → web personalization)

## WORKFLOW: /careers-portal-setup
DESCRIPCIÓN: Configurar portal de empleo
CUÁNDO_USAR: Reclutamiento activo

PASOS:
1. Integrar con ATS (Greenhouse, Lever, Workable) vía API
2. Listado de jobs filtrable por departamento, location, type
3. Job detail pages con SEO optimizado para cada posición
4. Application form con resume upload (parseo automático)
5. Employee value proposition destacado (beneficios, cultura)
6. Employee testimonials y "day in the life" content
7. Proceso de aplicación mobile-friendly
8. Auto-responder emails configurados
9. Referral program integration
10. Analytics: Source of hire, time to apply, drop-off points
